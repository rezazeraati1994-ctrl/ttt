# RepairReports v1

اپلیکیشن اندروید ثبت و جست‌وجوی گزارش‌های تعمیرات.

## امکانات نسخه 1
- ثبت، ویرایش و حذف گزارش
- جست‌وجو بر اساس مشتری، دستگاه، مدل، خرابی و توضیحات
- ذخیره محلی در SQLite
- ثبت تاریخ، کد خطا، اقدامات، قطعه، نتیجه، هزینه و وضعیت
- نمایش جزئیات هر گزارش

## ساخت پروژه
این پروژه برای Android Studio و Android Gradle Plugin 8.7.3 تنظیم شده است.

- Compile SDK: 35
- Min SDK: 23
- Target SDK: 35
- Java: 8

پروژه را در Android Studio باز کنید و اجازه دهید Gradle/Android SDK موردنیاز را دریافت یا تنظیم کند؛ سپس از Build > Build APK(s) استفاده کنید.

## نکته
داده‌ها در دیتابیس محلی `reports.db` ذخیره می‌شوند. در نسخه‌های بعدی می‌توان بکاپ، عکس، مشتری‌ها، قطعات، PDF و همگام‌سازی را اضافه کرد.
